DEPLOY USING YOUR EXISTING GITHUB REPOSITORY

1. Open your existing Swasthya repository on GitHub.
2. Open the repository's file list.
3. Add or replace the project files, preserving their folders.
4. Commit your changes to the main branch.
5. Open Settings → Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Select:
   Branch: main
   Folder: / (root)
8. Click Save.
9. Wait for GitHub Pages to publish your site.
